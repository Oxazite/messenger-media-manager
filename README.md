## ✨ Features

- **Custom stickers on PC**: Create, save and send custom stickers (as well as custom animated stickers!) as you wish with a simple right-click save.
- **Video support**: Send MP4, WebM, and MOV files with preserved quality.
- **Full-Screen Viewer**: Preview media with zoom, pan, and built-in file conversion mechanisms.
- **Organization**: Custom categories, search, favorites, with backup features to import and export media.
- **Automatic theme synchronization**: Seamlessly adapts between Messenger's Dark and Light modes.
- **Multilingual support**: Full English and Vietnamese localization with automatic interface language detection.
- **100% local & private**: All media is stored locally on your device.

## 🆕 What's New in v1.1.6

- **Vietnamese Localization (i18n)**: Comprehensive bilingual support across all drawer elements, tabs, options menus, modals, and status toasts, with automatic Facebook language detection.
- **Video Import Choice Dialog**: Redesigned video import prompt into a modern dual-card layout with direct video saving or one-click smooth GIF conversion.
- **Dynamic Theme Switcher**: 3-mode theme controls (Auto, Dark, Light) with synchronized, lockstep visual transitions and unified control styling.
- **Options Drawer Polish**: Refined options header alignment with standardized action badges and dynamic theme indicator labels.
- **Performance & Tooltip Refinements**: Polished tooltip layering, viewport boundaries, and memory optimization for large sticker libraries.
